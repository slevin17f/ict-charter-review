# 按集查案例与遮图练习

1. 从集号定位到下方对应卷。按品种、时段、模型和示例性质选一段；跨集重讲时保留不同问题和时间码。
2. 讲解时先报课程给出的背景、截至哪根 K 线及可见条件。让学习者先写候选目标、所待触发及什么情况会推翻判断，再揭示后续。
3. 用“已见／尚待／被后续否定”逐项批改。只给自述或示意的段落注明来源性质。无成交记录时，盈亏栏留空。
4. 返回集号、原视频定位、品种与周期、观察截止点、事前推演、原片结果及差异。纯计划讲可以用来解释规则；自编的数值练习标为合成题。

例如第 22 集 24:53 使用绘图工具解释变化后的价格路径。回答该例能否用于统计胜率时，应辨认画面编辑及其示意性质，并从真实成交样本中排除。第 32 集 05:50 可用于先标出订单块重测，再识别扩张腿中的缺口；账户收益需另有成交凭证。
