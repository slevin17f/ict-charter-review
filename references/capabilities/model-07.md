# 模型 7 · 复盘两种轮廓中的下行段

**输入**　历史图表或带时间的 OHLC、主周期和细化周期、事件日历、下方旧低或折价区域。要求按发生顺序交付进入下行段的证据、目标和作废条件。

1. 选与主周期对应的 20、40 或 60 个已结束交易日，跳过周日，标记范围、中点及下方目标。若预期做市商买入模型（MMBM），关注向下寻找折价区以形成底部的阶段，目标可在旧低下方；若是做市商卖出模型（MMSM），关注向上探顶后返回原始盘整区的阶段。两者都能有下行段。[第23集 01:03–04:56](https://www.youtube.com/watch?v=G4lhid5dh0I&t=63s)
2. MMSM 中先标上行侧第一、第二阶段再积累的位置，追踪顶部反转后向下破位、反弹至先前区域、再派发、续跌的顺序。保持跌势才继续复核；若价格持续上破对应的原再积累区，取消当前卖出轮廓。初始预计的顶部出现后价格持续上涨，同样需要作废。[第21集 77:48–78:30、82:51–83:31](https://www.youtube.com/watch?v=_7oZZ2bhEGU&t=4668s) · [第22集 22:37–23:55](https://www.youtube.com/watch?v=oheyS8MUqno&t=1357s)
3. 课内日内计划在第一或第二再派发阶段等向上回撤，伦敦或纽约开盘观察 15/5 分钟溢价 FVG 与不超过向上第三档的投射重合，或扫上方买方止损。记录对应的时段、反弹高点和 5 分钟触发。第 22 集把片段压缩和移位来讲解顺序；重建真实成交时必须使用有原始时间轴的行情。[第23集 03:40–05:17](https://www.youtube.com/watch?v=G4lhid5dh0I&t=220s) · [第22集 24:53–25:32](https://www.youtube.com/watch?v=oheyS8MUqno&t=1493s)
4. 模拟外汇计划课以共振位下方 5 pip 为限价、高点上方 20 pip 为止损，展示 20/40 pip 分批及 60 pip 后的余仓处理。课程另讲极端快速下跌和无法及时退出；若当时没有证据支持，把该分支记为事后情景，按原计划审阅。[第23集 05:17–06:56、14:50–15:29、19:37–20:15](https://www.youtube.com/watch?v=G4lhid5dh0I&t=317s)

**合成演练**　原始盘整 99–100，上行中先后出现 102–103、105–106 两段再积累，升至 109 后快速跌至 104。目标候选为原盘整。反弹至 105.5 时，应检查第二段旧区和低周期触发，未给 5 分钟数据就保留「再派发待核」。若随后直接重新站上 106 并继续创新高 110，则原下行方案作废；若先跌回 100，记为目标区触及。即使目标触及，也只有同时具备计划价、成交与时间记录才能评价一笔模拟交易。
