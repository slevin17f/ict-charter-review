# 常用术语

| 术语 | 本课复盘时的用法 |
|---|---|
| Draw on liquidity | 标记讲者预期价格会去测试的旧高、旧低或其他参考位，记录提出假设的时刻。 |
| Dealing range / equilibrium | 写下选定区间的高、低和中点；注明回看单位与采用的周期。 |
| PD array | 讲者用来组织溢价或折价参考的结构，复盘应画出具体类型和边界。 |
| FVG | 公允价值缺口。按三根蜡烛第一与第三根的极值找未重叠区；保留方向及周期。 |
| OB | 订单块。记录来源蜡烛、后续位移和重访时刻；相关模型另有筛选要求。 |
| OTE | Optimal Trade Entry，指定波段内的回撤候选位置；用课程对应讲次的锚点和过滤条件。 |
| SMT | 对照有预期相关性的市场，记录同一时段一方突破极值、另一方未确认的情况。 |
| CBDR / FLOUT | 第 5 模型的纽约晚间区间；见该卡核对窗口、宽度、投射步长。 |
| MM buy / sell model | 讲者用来归纳累积、上行、反转或下行的轮廓。标注价格路径时需说明处于反转哪一侧。 |
| OSOK | One Shot One Kill，本课第 9 模型，按周初锚点与计划分批复盘。 |
