# ICT Charter Review

中文 Agent Skill。用 13 个模型审阅历史价格图表、复核模拟计划，或按集定位课堂案例并进行遮图练习。案例条目涵盖行情回放、示意、假设和仓位算例，同一走势可服务于不同问题。

## 安装到 Codex

将这个仓库克隆为个人技能目录下的独立文件夹，在新会话调用 `$ict-charter-review`。技能由 Markdown 构成，无运行时依赖。

```sh
git clone https://github.com/slevin17f/ict-charter-review.git ~/.codex/skills/ict-charter-review
```

## 使用

- “用模型 9 检查这份历史复盘。先核对回看区间和周初锚点。”
- “用第 32 集的 EUR/USD 案例出一道遮图题，等我回答后再给出后续。”
- “第 22 集的图能否作为一笔真实成交的证据？给我对应时码。”

[技能入口](SKILL.md)提供模型路由。按集阅读案例可打开[第 1–10 集](resources/cases-01-10.md)、[第 11–23 集](resources/cases-11-23.md)和[第 24–34 集](resources/cases-24-34.md)。

## 来源与范围

课程作者为 The Inner Circle Trader。中文复盘流程、案例说明与合成练习为独立整理，课堂观点及示例参数均按对应视频的时间链接归属原讲。本项目与课程作者无隶属关系。课程画面、音视频与字幕的权利归其各自权利人。[原始播放列表](https://www.youtube.com/playlist?list=PLVgHx4Z63paasvEhegIwtiaGalrQphFg3)

历史回放侧重当时可见的条件、价格与订单差异以及来源定位。案例核对不构成策略胜率或账户实际收益的验证。
